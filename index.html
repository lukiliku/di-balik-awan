Bab 2Kenalan AWS · AWS itu apa?

📖 Kumpulin mulai dipakai satu kampus, dan server sendirimu mulai ngos-ngosan. Kamu putuskan pindah ke cloud, pakai AWS.

Jadi, AWS itu apa?

AWS singkatan dari Amazon Web Services. Gampangnya, tempat kita bisa sewa komputer lewat internet.

  • Punya Amazon, sudah ada sejak 2006.
  • Bisa sewa server, tempat simpan file, database, sampai jaringan. Nggak perlu beli hardware sendiri.
  • Layanannya ada 200 lebih. Bayarnya sesuai pakai, kayak argo taksi tadi.
  • Ada Region di Jakarta sejak Desember 2021, jadi data kita bisa disimpan dekat.

Klik salah satu layanan 👆

Sumber: aws.amazon.com/what-is-aws & aws.amazon.com/about-aws/global-infrastructure, dicek Oktober 2026.

Bab 2Kenalan AWS · Server & gudang file

EC2 buat server, S3 buat file

🖥️ Amazon EC2: sewa server

EC2 (Elastic Compute Cloud) itu tempat sewa server. Pilih ukurannya, nyala dalam hitungan menit, bayar per jam, dan bisa dimatikan kapan aja.

(harga = ilustrasi)
💤 Belum ada server

🪣 Amazon S3: gudang file

S3 (Simple Storage Service) buat nyimpen tugas, foto, video, sebanyak apa pun. Bedanya sama EC2, di sini kamu nggak ngurus server sama sekali. Tinggal upload.

💡 EC2 dan S3 bakal dipakai lagi di game arsitek di Bab 4.

Bab 2Kenalan AWS · Load balancer & Auto Scaling

Satu server nggak cukup? Pakai load balancer & auto scaling

⚖️ Load balancer

Mirip petugas di pintu masuk yang mengarahkan antrean ke kasir yang lagi kosong. Kalau satu kasir tutup, antreannya dialihkan ke kasir lain.

📈 Auto Scaling

Waktu ramai, server ditambah sendiri. Habis ramai, dikurangi lagi. Jadi kamu nggak bayar server yang nganggur.

Harga = ilustrasi.

👉 Servernya sudah kuat. Tapi kalau yang buka Kumpulin ada di kota yang jauh, gimana supaya tetap cepat?

Bab 2Kenalan AWS · Cepat dari mana saja

CloudFront: taruh salinannya dekat kamu

Contoh gampangnya aplikasi nonton film: film yang lagi ramai ditonton disimpan salinannya di server dekat kotamu, jadi nggak perlu diambil jauh-jauh dari server pusat setiap ada yang nonton. Sama juga buat materi kuliah di Kumpulin. Misalnya server Kumpulin ada di Amerika dan mahasiswanya di Jakarta: coba nyalakan atau matikan CloudFront, terus klik Buka website beberapa kali.

👆 Coba klik Buka website.

📠 Cache itu kayak tukang fotokopi depan kampus. Satu orang ambil materi aslinya jauh-jauh ke server di Amerika, terus salinannya disimpan dekat kalian (CloudFront Jakarta). Yang lain tinggal ambil di situ. Lebih cepat, dan server aslinya nggak kewalahan.

CloudFront: 750+ Points of Presence di 100+ kota, 50+ negara, termasuk Jakarta (aws.amazon.com/cloudfront/features, dicek Oktober 2026). Angka waktu = ilustrasi.

👉 Datanya cepat sampai. Tapi aman nggak sih di sana?
